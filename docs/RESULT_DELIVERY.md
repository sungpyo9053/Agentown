# 결과 전달

결과 파일 본체는 기본적으로 저장하지 않는다. DB에는 소유자, 실행, 파일명, MIME, 외부 HTTPS URL, 만료 시각만 기록한다. 다운로드 API는 소유권과 만료, HTTPS, DNS 해석 결과와 내부 주소 여부를 검증한 뒤 기본적으로 직접 URL로 리다이렉트한다.

하네스는 최종 결과 담당 단계와 `AUTO`, `TEXT`, `MARKDOWN`, `HTML`, `JSON`, `CSV`, `EXTERNAL` 결과 계약을 가진다. 실행 화면과 다운로드 API는 이 계약을 사용하며 검수 기록이나 마지막 단계의 값을 무조건 최종 결과로 취급하지 않는다. HTML은 생성 텍스트를 escape해 안전한 문서로 렌더링하고, 전체 실행 JSON은 진단용 보조 다운로드로 분리한다.

PDF, PPT, DOCX, 이미지, 영상, 음성처럼 플랫폼 내부에서 렌더링하지 않는 형식은 `EXTERNAL`을 사용한다. 이때 외부 제공자가 생성한 Artifact의 실제 MIME, 파일명, 만료 URL을 그대로 사용한다.

직접 다운로드가 불가능한 경우 `proxyDownload=true`를 명시하면 최대 10개의 동시 다운로드만 허용하는 `StreamingResponseBody` 프록시를 사용한다. 외부 응답 스트림을 64 KiB 단위로 전달하여 전체 파일을 JVM 메모리에 적재하지 않는다. 리다이렉트는 따라가지 않고, 외부 오류와 만료 URL은 명시적 오류로 반환한다.
