Agentown Mac Runner
===================

이 파일들은 사용자가 직접 만드는 파일이 아닙니다.
Agentown 개발팀이 제공하며, Agentown의 'AI 연결' 화면에서 내려받습니다.

설치 위치
1. 브라우저의 다운로드 폴더에서 Agentown-Mac-Runner.zip을 찾습니다.
2. 압축을 풀면 만들어지는 'Agentown Mac Runner' 폴더를 원하는 위치로 옮깁니다.
3. 세 command 파일과 runner.mjs를 같은 폴더에 둡니다.

처음 한 번
1. Agentown 웹의 AI 연결 화면에서 Runner 연결 토큰을 만듭니다.
2. 'Agentown Runner 연결.command'를 더블클릭합니다.
3. 토큰을 붙여 넣고 Codex 또는 Claude 계정 로그인을 완료합니다.

평소 사용
- 켜기: Agentown Runner 시작.command
- 끄기: Agentown Runner 종료.command

주의
- ChatGPT/Claude 비밀번호나 로그인 토큰을 Agentown에 입력하지 않습니다.
- 일회용 Runner 토큰만 연결 파일에 붙여 넣습니다.
- .agentown 폴더에는 연결 정보가 있으므로 다른 사람에게 공유하지 마세요.
